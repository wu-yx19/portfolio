# Minimal Portfolio Website

The site uses plain HTML and CSS. No build step or JavaScript is required.

## Preview

Open `index.html` in a browser.

## Project pictures

The project pictures are stored in the `assets` folder:

- `LargeOffset.png`
- `Breast.png`
- `Hand.png`

To replace one, use the same filename or update its image path in `index.html`.

## Update text

All visible text is directly inside `index.html`. Search for the project title or section heading you want to edit.
