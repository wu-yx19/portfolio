# Ashley Wu - Research Portfolio

This repository contains my personal research portfolio website. It highlights my work in 3D computer vision, augmented reality, surgical navigation, Gaussian splatting, and human-centered visual computing.

## Website Content

The portfolio includes:

- Education and technical skills
- Featured research projects
- Additional research and engineering projects
- Selected publications
- Selected presentations and honors
- Contact information and downloadable resume

## Featured Projects

- Free-Viewpoint 4D Gaussian Splatting for Dynamic Surgical Scene Reconstruction
- State Estimation-Based Augmented Reality Guidance for Breast Surgery
- Joint Hand Segmentation and Depth Estimation from Monocular Video

## Technology

The website is built with plain HTML and CSS. It does not require a framework, package manager, build step, or JavaScript.

## Local Preview

Open `index.html` in a web browser.

For a local web server, run the following command from the repository folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating the Website

- Edit page content in `index.html`.
- Edit colors, spacing, typography, and responsive layouts in `styles.css`.
- Store images and PDF files in the `assets` folder.
- Keep asset filenames and paths consistent with the references in `index.html`.

## Deployment

The site can be published with GitHub Pages:

1. Open the repository's **Settings** page.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder.
5. Save the configuration and wait for the deployment to complete.
